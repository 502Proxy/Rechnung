# Sicherheitsrichtlinie

## Unterstützte Versionen

Sicherheitsupdates gibt es nur für die jeweils neueste Version auf `main`.

## Sicherheitslücke melden

Melde Sicherheitslücken bitte **nicht** in öffentlichen Issues. Nutze stattdessen [GitHub Private Vulnerability Reporting](../../security/advisories/new) dieses Repositorys.

Hilfreich sind:

- eine Beschreibung der Lücke und ihrer Auswirkung
- Schritte zum Nachstellen
- die betroffene Version oder der betroffene Commit

Du bekommst innerhalb von 7 Tagen eine Rückmeldung.

Wie die App deine Daten schützt, steht in [docs/security.md](docs/security.md).
